# Carambola 0.1 — archived release notes

The original Git tag used the legacy label `v0.1.0`. The public two-part
version for this archive is `0.1`; the existing GitHub release and tag are not
changed by this local documentation update.

Carambola is a tray-based desktop screenshot and annotation app. Start a capture from the system tray or a keyboard shortcut, select an area, annotate it, then copy or save the result as a PNG.

## Features

- Screen capture with a dimmed overlay and a movable, resizable selection.
- Pen, arrow, rectangle, triangle, circle, text, and pixelation mosaic annotations.
- Annotation undo and redo, clipboard copy, and PNG export to the Pictures folder.
- Configurable capture shortcut, Start on Boot, and screenshot notifications.
- OCR text extraction on Windows.

## Available download

- **macOS Apple Silicon (ARM64):** `Carambola_0.1.0_aarch64.dmg`

This release is limited to the verified ARM64 DMG. No Windows installer or Linux package is included. Intel macOS is not tested.

## Install on macOS

1. Open the DMG and drag **Carambola** to **Applications**.
2. Start Carambola. When macOS asks, allow Screen Recording under **System Settings → Privacy & Security → Screen & System Audio Recording**.
3. Restart Carambola after changing the permission.

This build is not Developer ID signed and is not notarized. macOS may show a security warning or block the app from opening.

## Known limitations

- Packaged capture, annotation, Settings, clipboard/save export, and notification flows have not received complete interactive runtime QA.
- Windows runtime behavior and installer generation are unverified; Linux build, packaging, and runtime behavior are unverified.
- Linux capture and global shortcuts use X11. Native Wayland behavior is not verified.
- OCR is available only on Windows and is not available in this macOS build.
- macOS Intel, multi-monitor behavior, and display scaling have not been tested.
- Capture latency and memory use have not been measured.
